# Kinopoisk Unlock

Userscript для Tampermonkey, который добавляет на поддерживаемые страницы Кинопоиска отдельную кнопку перехода на Kino.vin.

## Возможности

- Поддержка страниц фильмов и сериалов на `kinopoisk.ru` и `hd.kinopoisk.ru`.
- Компактная кнопка с иконкой, адаптивным видом и состояниями hover, active и focus.
- Корректная обработка клиентской навигации через History API и кнопок «Назад» / «Вперёд».
- Повторное добавление кнопки после динамического обновления интерфейса.
- Ограничение наблюдения за DOM одним обновлением на кадр, чтобы не запускать поиск десятки раз подряд.
- Резервное извлечение ID HD-страницы, даже если `__NEXT_DATA__` отсутствует.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [файл userscript](https://github.com/TaronJar/kinopoisk-unlock/raw/main/kinopoisk-unlock.user.js).
3. Подтвердите установку в Tampermonkey.
4. Откройте страницу поддерживаемого фильма или сериала.

## Поддерживаемые адреса

- `https://www.kinopoisk.ru/film/...`
- `https://www.kinopoisk.ru/series/...`
- `https://www.kinopoisk.ru/anime/...`
- `https://www.kinopoisk.ru/media/...`
- `https://hd.kinopoisk.ru/film/...`
- `https://hd.kinopoisk.ru/series/...`

Фактическая доступность страниц и совместимость с текущей разметкой сайта могут меняться.

## Разработка

Основная логика находится в одном файле `kinopoisk-unlock.user.js`, чтобы установка и автообновление через Tampermonkey оставались простыми.

Перед выпуском новой версии рекомендуется проверить:
- обычные страницы фильмов и сериалов;
- HD-страницы с `__NEXT_DATA__` и без него;
- переход между карточками без полной перезагрузки;
- навигацию браузера «Назад» и «Вперёд»;
- повторную отрисовку блока действий.

## Примечание

Кнопка перенаправляет пользователя на внешний сервис Kino.vin. Автор проекта не контролирует его доступность, безопасность, содержимое и соблюдение прав на материалы. Проверяйте адрес назначения перед использованием.
