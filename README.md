## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для своего браузера.
2. [Откройте файл Kinopoisk Unlock](https://github.com/TaronJar/kinopoisk-unlock/raw/main/kinopoisk-unlock.user.js).
3. Подтвердите установку в Tampermonkey.
4. Перейдите на страницу фильма или сериала на Кинопоиске. Кнопка **«Смотреть»** появится рядом с действиями страницы.

При выпуске новых версий Tampermonkey сможет получать обновления по указанному в скрипте адресу.

## Возможности

- **Быстрый переход.** Кнопка «Смотреть» открывает соответствующую страницу на [Kino.vin](https://kino.vin/).
- **Нативный вид.** Компактная кнопка с иконкой, аккуратными состояниями наведения, нажатия и клавиатурного фокуса.
- **Поддержка SPA.** Кнопка корректно обновляется при переходах по сайту без полной перезагрузки страницы.
- **Динамический интерфейс.** Скрипт повторно находит место для кнопки после обновления элементов страницы.
- **Обработка ID.** Для HD-страниц предусмотрено извлечение идентификатора из данных страницы и резервный вариант, если `__NEXT_DATA__` недоступен.
- **Лёгкая установка.** Вся логика находится в одном userscript-файле, без отдельного приложения или сборки.

## Поддерживаемые страницы

Скрипт работает на следующих типах страниц:

| Сайт | Разделы |
| --- | --- |
| `www.kinopoisk.ru` | `/film/`, `/series/`, `/anime/`, `/media/` |
| `hd.kinopoisk.ru` | `/film/`, `/series/`, `/anime/`, `/media/` |

Поддержка конкретной страницы зависит от доступности её данных и текущей разметки Кинопоиска. Сайт может менять интерфейс без предупреждения, поэтому отдельные селекторы со временем могут потребовать обновления.

## Как это работает

1. Userscript проверяет адрес и определяет, относится ли текущая страница к поддерживаемому разделу.
2. Извлекает идентификатор фильма или сериала из URL либо данных страницы.
3. Находит подходящий блок действий и добавляет кнопку.
4. При клиентской навигации и динамических изменениях интерфейса синхронизирует кнопку с текущей страницей.
5. По нажатию открывает адрес назначения на Kino.vin.

Для отслеживания изменений используются History API и MutationObserver. Повторная синхронизация ограничивается кадром анимации, чтобы не выполнять лишнюю работу при серии DOM-изменений.

## Разработка и проверка

Основной код находится в файле `kinopoisk-unlock.user.js`. Такая структура упрощает установку и автоматическое обновление через Tampermonkey.

Перед выпуском изменений проверьте:

- страницы фильмов, сериалов, аниме и других поддерживаемых разделов;
- обычные и HD-адреса;
- извлечение ID на HD-страницах с `__NEXT_DATA__` и без него;
- переходы между страницами без полной перезагрузки;
- кнопки браузера «Назад» и «Вперёд»;
- повторную отрисовку блока действий;
- корректность открываемого адреса Kino.vin.

### Автоматическая проверка

GitHub Actions выполняет проверку синтаксиса JavaScript командой:

```bash
node --check kinopoisk-unlock.user.js
```

Это базовая проверка синтаксиса, а не полноценный браузерный тест. Поведение на живом сайте следует дополнительно проверять вручную.

## Конфиденциальность и ограничения

- Скрипт предназначен для добавления кнопки и перехода на внешний сайт.
- Он не является частью Кинопоиска или Kino.vin и не связан с их владельцами.
- Доступность Kino.vin, содержимое страниц и условия использования внешнего сервиса находятся вне контроля проекта.
- Перед переходом убедитесь, что адрес назначения соответствует ожидаемому.
