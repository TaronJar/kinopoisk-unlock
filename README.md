# Kinopoisk Unlock

Tampermonkey-скрипт для бесплатного просмотра фильмов и сериалов с Кинопоиска.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/)
2. Откройте `userscript.js` или установите через Raw-ссылку
3. Скрипт активируется автоматически на страницах kinopoisk.ru

## Как работает

Кнопка **"Смотреть бесплатно"** появляется рядом с кнопкой **"Буду смотреть"** на странице фильма или сериала. При нажатии открывает плеер с доступными источниками.
